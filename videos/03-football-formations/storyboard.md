## 参考片拆解：我们借用了什么

三个参考片：《稳定婚姻》（数学模型）、《运气的形状》（概率史）、《Opus 家族史》。它们共用一套组织方式：

| 手法 | 参考片里的样子 | 这支片怎么用 |
|---|---|---|
| **冷开场：一个物件 + 一句悬念** | 一颗骰子“落下之前，谁也不知道答案”；洞穴手印“四万年前” | 晨雾里一只旧皮球：“球场上，永远是十一个人。” |
| **片名卡** | 拉丁小字 DE FORMA FORTUNAE + 大号宋体片名 + 一行副题 | THE SHAPE OF ELEVEN + 「十一人」+ 足球阵型 150 年 |
| **先教会读法** | 稳定婚姻先用两对人讲清“稳定”的定义，再上 4×4 | 先用 4-4-2 讲清“数字从后往前读、门将不算” |
| **年份驿站** | 左上角大号年份（数字滚动），下面“地点 · 人物”；右上角书名 + 红色印章 | 每个时代一站：左上「1925 / 伦敦 · 查普曼」，右上放出处（规则、比赛、球队） |
| **每站一个主物件** | 账本、钱币、花瓶、高尔顿板 | 每站一张场景画 + 一块“战术板”演示 |
| **埋一个问题，后面回收** | “回到 1494 年那道题——” | 1880s 的金字塔先埋下，结尾“回到 1880 年代那座金字塔” |
| **家谱式总复盘** | Opus 的“家谱”：一根墨枝，开出一朵朵红花 | 「阵型家谱」：1872 → 今天，十朵花，最后一朵连回金字塔 |
| **结尾回到开场画面** | 洞穴手印 → 今天的笔记本电脑“四万年后，我们仍在留下手印” | 晨雾里的皮球 → 傍晚街边的球场，孩子们在争谁守门 |
| **字幕** | 居中宋体中文，下面一行细斜体英文，关键词点红 | 一样；每条 ≤ 18 字，一句一屏 |
| **片尾** | 片名 + 出品 + 极小号参考文献 | 片名卡复现 + 参考来源小字 |

一个时代的画面色调跟着变（参考 Opus：洞穴橙 → 海底青 → 伊斯兰金 → 水墨白 → 雪夜蓝），但战术板始终是同一块米白纸 + 朱红点，作为全片的“锚”。

## 版式（所有镜头通用）

- **左上 · 年份角标**：Noto Serif Display 72px 年份（换站时数字滚动到新年份）+ 细横线 + 「地点 · 人物」宋体 22px。参考《运气的形状》。
- **右上 · 出处签**：小号斜体英文出处 + 中文书名号 + 朱红方印（如「规」「赛」）。只在有明确出处的站出现。
- **底部字幕**：中文宋体 40px 居中，下方细线，英文 Noto Serif Italic 22px，关键词朱红。
- **战术板**：米白纸面、细墨线球场、墨点 = 主角球队、朱红点 = 强调、灰点 = 门将。
- **转场**：场景画 → 战术板用“纸面推入”（纸从画面一侧滑进来盖住场景）；站与站之间年份滚动 + 交叉淡化。

### S04 · 1872 冲锋年代（0:24–0:42）
- **左上：** 1872 ／ 格拉斯哥 · 汉密尔顿新月球场
- **右上：** *The Graphic, 1872* 「画」
- **画面：** G02 维多利亚时代球赛场景铺底，F01 1872 年英苏之战版画（公有领域，原图较小）做成一张泛黄的报纸卡片浮在画面中央。→ 纸面推入 C02：左英格兰 1-1-8 一窝蜂往前，右苏格兰 2-2-6 一条朱红传球虚线串起来。比分 0 : 0 落下。
- **字幕：**
  1. 第一场国际比赛，英格兰对苏格兰。｜The first international: England v Scotland.
  2. 英格兰摆出 1-1-8：八个前锋，带球往前冲。｜England play 1-1-8 — eight forwards, all charging.
  3. 苏格兰少放两个前锋，开始**传球**。｜Scotland hold two back, and **pass**.
  4. 0 比 0。｜Nil–nil.

### S05 · 1880s 金字塔（0:42–0:56）
- **左上：** 1880s ／ 英格兰北部 · 普雷斯顿
- **画面：** G03 工业小城球场，烟囱与暮色；F06 普雷斯顿 1888–89 冠军队合影作为老照片卡片滑入。→ C03：2-2-6 的一个前锋撤到中场，变成 2-3-5，朱红三角形从后往前展开。
- **字幕：**
  1. 传球，就需要有人在中间接应。｜Passing needs someone in the middle.
  2. 再撤一个人：2-3-5。｜Pull one more back: 2-3-5.
  3. 画出来，像一座**金字塔**。｜Drawn out, it's a **pyramid**.
  4. 记住它。它会回来的。｜Remember it. It will come back.

### S06 · 1925 一条规则（0:56–1:20）
- **左上：** 1925 ／ 伦敦 · 越位规则修改
- **右上：** *Laws of the Game* 「规」
- **画面：** G04 台灯下的旧规则书和钢笔（像 Opus 片里图灵的打字机）。→ C04 两块小球场：越位线从“3 人”跳到“2 人”，朱红前锋一步插到身后。→ C05 进球柱状图：1192 涨到 1703，“+511”跳出。→ C06 球场竖起，中场点后撤成第三中卫，连线浮现 **W** 和 **M**。
- **字幕：**
  1. 1925 年，越位规则改了。｜In 1925, the offside law changed.
  2. 进攻者前面，从需要 3 名对手，变成 2 名。｜From three defenders needed to two.
  3. 下一个赛季，进球多了 **500 多个**。｜Next season: **500+ more goals**.
  4. 阿森纳的查普曼，把中场撤回来，当第三个后卫。｜Arsenal's Chapman pulled a midfielder back.
  5. 上面是 W，下面是 M。｜A W on top. An M below.

### S07 · 1953 温布利（1:20–1:38）
- **左上：** 1953.11.25 ／ 伦敦 · 温布利
- **右上：** 比分签 3 : 6

- **字幕：**
  1. 二十多年后，匈牙利来到温布利。｜Decades later, Hungary came to Wembley.
  2. 他们的 9 号，不待在前面，｜Their number 9 didn't stay up front —

### S09 · 两条路（1:50–2:12）
- **左上：** 1960s–1974 ／ 米兰 · 阿姆斯特丹
- **画面：** 画面竖向一分为二。左：G07 米兰夜色球场（冷蓝）+ C09 门闩：后卫线后多出一个蓝灰色自由人。右：F04 1974 决赛照片（CC0）+ C10 全攻全守：朱红点画着弧线互换位置。最后左右合拢成一块战术板。
- **字幕：**

  2. 意大利人在后卫线后再放一个人——**门闩**。｜Italy added one more behind the line: **the bolt**.

  1. 萨基的米兰：两条线压得很紧，一起往前推。｜Sacchi's Milan: two tight lines, pushing up together.
